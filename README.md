# AI Travel Agent

## Overview

AI Travel Agent is an intelligent travel planning assistant that helps users discover destinations, generate itineraries, estimate budgets, and receive personalized travel recommendations.

## Problem Statement

Travelers often spend significant time searching across multiple websites for destination information, accommodation options, transportation details, and travel guidance. This project aims to simplify travel planning through an AI-powered assistant.

## Features

* Personalized travel recommendations
* Itinerary generation
* Budget estimation
* Destination discovery
* Travel guidance using AI

## Technology Stack

* Langflow
* IBM Granite
* IBM Watsonx.ai
* IBM Cloud
* RAG (Retrieval-Augmented Generation)
* FAISS/Chroma Vector Database
